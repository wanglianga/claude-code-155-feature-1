# 澄心瑜伽 · 私教全流程管理（体验课测评 / 风险动作限制 / 排课 / 续费 / 转教练）

城市瑜伽馆私教业务的一体化页面：**会员、顾问、教练** 三个角色围绕 **同一套训练记录** 协作 ——
从体验课预约、教练测评、购课排课，到每节课的课后记录、请假改期、不适上报、换教练与续费跟进，
每一次疼痛、缺勤、训练效果和课程调整都会沉淀为后续排课与续费沟通的依据。

**运动风险动作限制**：体验课/训练中发现会员某部位不适（如腰椎、膝盖），教练在测评页结构化标记
**禁止动作、替代动作、替代器械与辅助动作**；限制在会员维度生效 —— 其他教练排课/代课自动看到高风险体式
与器械准备提醒；前台为会员报团课时自动读取限制、拦截高风险课程并推荐低强度替代；会员坚持挑战高难度体式时，
教练须再次告知风险并记录「拒绝 / 降阶调整 / 知情同意后挑战」。

- 技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端 SPA，数据存 localStorage，可一键重置演示数据）
- 项目类型：前端（无后端业务接口，故不提供 Swagger/OpenAPI）

## 快速启动

### 方式一：Docker（一键）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

也可手动：`docker build -t yoga-pt-studio . && docker run -p 8080:80 yoga-pt-studio`

### 方式二：本地开发

```bash
npm install
npm run dev        # http://localhost:5173
```

### 生产构建与预览

```bash
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # http://localhost:4173
```

2. **购课排课**：会员张倩登录 → 主页确认购买推荐套餐 → 自动生成课包、每周排课、请假规则与续费提醒基线。
3. **上课记录**：教练林岚登录 → 周课表点王晓彤的待上课 → 填完成动作/体感/疼痛变化/家庭练习 → 下节课重点自动同步。
4. **异常闭环**：
   - 会员王晓彤 →「请假与申请」上报膝盖不适 → 教练林岚在会员档案中做「课程调整」→ 顾问在「异常工单」办结；
   - 教练周远在周课表点「请假」→ 顾问在工单中为何静的课改期补课；
   - 会员孙悦申请换教练 → 顾问在工单中选择新教练 → 历史测评与全部课后记录完整交接（新教练视角可见同一份档案）。
5. **续费**：顾问登录 → 看板「续费提醒」→ 进入赵磊的会员 360° →「基于训练记录生成要点」（出勤、疼痛趋势、教练备注，而非只看剩余课时）→ 保存跟进；选「已续费」则新课包自动衔接。
6. **边界**：顾问在会员 360° 看到的教练专业档案为只读锁定卡（🔒），不可编辑；教练的测评与风险提示不会变成销售话术。
7. 右上角「重置演示数据」可随时恢复初始场景。

### 运动风险动作限制（本功能演示路径）

种子数据已预置：**张倩（腰椎受限，禁轮式/犁式等）**、**王晓彤（右膝受限，禁跑跳/深蹲>90°）**，以及 5 节低/中/高强度团课。

8. **测评页标记**：教练苏晴登录 → 本周课表（或重置后对李敏的体验课走「上课记录 → 测评」）→ 测评页底部「运动风险动作限制」逐部位录入 *禁止动作 / 替代动作 / 替代器械 / 辅助动作*，提交后随测评签名锁定，并在会员维度生效。
9. **排课自动提醒（其他教练也可见）**：任一教练登录 →「本周课表」：受限会员的待上课卡片变红，显示「⚠️ 腰椎受限 · 避开高风险体式」「🧰 备：瑜伽抱枕、瑜伽砖…」；下方「会员运动风险动作限制（全队共享）」列出全队受限会员（含其他教练会员），代课也据此避开。
10. **课前准备 + 高难度二次确认**：点受限会员的待上课进入课后记录页，顶部出现完整「课前风险提醒」（禁忌/替代/器械/辅助）；若会员坚持挑战，点「再次告知风险并记录」→ 选体式与部位、选 *已拒绝 / 已降阶调整 / 知情同意后挑战*、勾选「已当面告知」、填写方案后保存，留痕进入时间线与会员档案。
11. **团课前台提示**：顾问登录 →「团课前台」：
    - 选 **张倩** 报名「阿斯汤加 · 后弯工作坊」（高强度，含轮式/犁式）→ 红色拦截，提示命中禁忌并推荐「脊柱养护 · 阴瑜伽」等低强度课，可一键改报；会员坚持则需填写知情登记后报名（留痕并通知教练）。
    - 选张倩报名「脊柱养护 · 阴瑜伽」（低强度、体式均为替代动作）→ 直接成功；报名中强度「核心塑形」时显示黄色「谨慎」提示。
    - 花名册中受限会员带 ⚠️部位 角标，带课教练可见。
12. **档案与解除**：教练在会员档案「运动风险动作限制」可训练中新增限制或解除（保留历史）；会员/顾问在专业档案、训练记录、会员 360° 与时间线中均能看到同一套限制与风险确认记录。

## 目录结构

```
src/
  types/index.ts        # 领域模型（预约/测评/风险动作限制/风险确认/团课/课包/排课/记录/工单/续费/时间线）
  data/seed.ts          # 演示种子数据（覆盖六类异常 + 腰椎/右膝风险限制 + 5 节团课）
  stores/               # Pinia：auth（登录）+ data（全部业务动作、风险匹配与看板计算）
  components/           # 训练时间线、专业档案、课包卡、风险动作限制卡、标签输入
  views/
    member/             # 预约体验课、我的主页（课包/课表/购课）、训练记录、请假与申请
    coach/              # 周课表（风险角标+器械提醒+全队风险）、会员档案（维护限制）、课后记录（课前提醒+二次确认）、体验测评（标记禁止/替代动作）
    consultant/         # 经营看板、安排体验课、团课前台（风险拦截+低强度推荐）、异常工单、会员 360°
```
