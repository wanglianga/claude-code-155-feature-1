# 澄心瑜伽 · 私教全流程管理（体验课测评 / 排课 / 续费 / 转教练 / 运动风险动作限制）

城市瑜伽馆私教业务的一体化页面：**会员、顾问、教练** 三个角色围绕 **同一套训练记录** 协作 ——
从体验课预约、教练测评、购课排课，到每节课的课后记录、请假改期、不适上报、换教练与续费跟进，
每一次疼痛、缺勤、训练效果和课程调整都会沉淀为后续排课与续费沟通的依据。

**运动风险动作限制**：教练在体验课测评页（或会员档案复评时）成对标记「禁止动作 ↔ 替代动作」，
并登记替代器械与辅助动作；限制生效后，其他教练排课自动看到禁忌提醒与器械准备清单，
会员报名团课时前台收到风险提示并推荐低强度课程；会员若坚持挑战高难体式，教练须再次告知风险
并记录「调整方案 / 拒绝 / 坚持（已告知风险）」。

- 技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端 SPA，数据存 localStorage，可一键重置演示数据）
- 项目类型：前端（无后端业务接口，故不提供 Swagger/OpenAPI）

## 快速启动

### 方式一：Docker（一键）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

也可手动：`docker build -t yoga-pt-studio . && docker run -p 8080:80 yoga-pt-studio`

### 方式二：本地开发

```bash
npm install
npm run dev        # http://localhost:5173
```

### 生产构建与预览

```bash
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # http://localhost:4173
```

3. **上课记录**：教练林岚登录 → 周课表点王晓彤的待上课 → 填完成动作/体感/疼痛变化/家庭练习 → 下节课重点自动同步。
4. **异常闭环**：
   - 会员王晓彤 →「请假与申请」上报膝盖不适 → 教练林岚在会员档案中做「课程调整」→ 顾问在「异常工单」办结；

7. 右上角「重置演示数据」可随时恢复初始场景。

## 运动风险动作限制 · 验证路径

> 初始数据已预置：王晓彤「右膝」、张倩「腰椎」两张高风险限制卡（各含 4/3 组禁止↔替代动作、替代器械、辅助要点），本周 5 节团课（2 高 / 1 中 / 2 低），张倩已报名低强度阴瑜伽团课。

1. **测评页标记限制**（李敏体验课全流程）：顾问陈曦 →「安排体验课」为李敏安排 → 教练苏晴登录，周课表点该体验课 → 填课后记录 → 测评页勾选「同步建立风险动作限制」→ 从风险体式库选择（如「头倒立 / 肘倒立」自动带出替代动作、器械、辅助建议）→ 签名提交，限制立即生效。
2. **其他教练排课自动提醒**：教练林岚登录 → 周课表中王晓彤的待上课带 ⚠️ 角标，下方提示「避开右膝禁忌体式 · 备瑜伽椅/靠墙」；会员表新增「风险动作限制」列。点进待上课：
   - 顶部红色风险卡列出**需提前准备的替代器械与辅助动作**；
   - 在「完成动作」里填入禁忌体式（如「波比跳」）会实时红色预警并阻止提交；
   - 点「会员坚持高难体式？二次确认登记」→ 选择调整/拒绝/坚持完成，勾选「已告知风险」后留痕，记录同步到时间线与会员档案。
3. **会员档案复评管理**：教练 → 任意会员「档案」→ 可「复评新增限制」（同样即时生效）或「解除限制」（须填解除依据），并查看全部二次确认记录。
4. **前台团课风险提示**：顾问陈曦 → 顶部「团课报名」→
   - 选择**王晓彤**：力量流/阿斯汤加（高强度）红色标出命中禁忌体式与替代动作，页面推荐低强度安全课；
   - 点「会员坚持报名（风险告知）」→ 可一键套用建议话术，**必须勾选「已当面告知风险」才能报名**，告知说明写入训练时间线；
   - 选择**张倩**：可看到其腰椎限制，已报名的阴瑜伽团课标记为安全；低强度推荐区只列出不含其禁忌的课程。
5. **教练团课现场**：教练（如周远）周课表「我带的团课」→「课前核对/现场登记」→ 逐人查看命中禁忌、准备替代器械并勾选确认；会员现场坚持原动作可再次登记二次确认。
6. **会员与顾问只读可见**：会员王晓彤/张倩登录后主页有风险横幅，「我的训练记录」可查看限制卡、确认记录与已报团课；顾问在会员 360° 只读查看风险限制（不可改写），团课报名的风险告知结论在时间线可追溯。

## 目录结构

```
src/
  types/index.ts        # 领域模型（新增：风险限制/风险确认/团课）
  data/
    seed.ts             # 演示种子数据（预置腰椎/右膝风险限制、本周团课）
    catalog.ts          # 风险体式库、替代器械/辅助建议、团课模板、禁忌匹配算法
  stores/               # Pinia：auth（登录）+ data（风险限制、二次确认、团课报名等全部业务动作）
  components/           # 训练时间线、专业档案、课包卡
                        # + 风险提示横幅 / 风险限制只读卡 / 限制编辑器 / 高难体式二次确认弹窗
  views/
    member/             # 主页（风险横幅+已报团课）、训练记录（风险卡）、预约、请假与申请
    coach/              # 周课表（风险角标+团课）、会员档案（复评/解除限制）、课后记录（禁忌预警）、
                        #   体验测评（标记禁止/替代动作）、团课课前核对与现场登记
    consultant/         # 经营看板、安排体验课、团课报名（风险提示/低强度推荐/告知留痕）、
                        #   异常工单、会员 360°（风险限制只读）
```
